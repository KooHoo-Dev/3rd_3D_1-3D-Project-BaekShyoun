거북이 팔꿈치 조정용 모델 — Turtle Elbow Ready

목적
기존 거북이의 생김새를 유지하면서 아래팔을 팔꿈치처럼 굽힐 수 있도록
앞다리 웨이트와 보조 뼈를 준비한 모델입니다. 완성 투척 애니메이션은 아닙니다.

변경 사항
- 양쪽 팔꿈치에 elbow.Support.L / elbow.Support.R 보조 뼈 추가.
- 양쪽 앞발의 242개 정점씩, 총 484개 정점의 웨이트 조정.
- 팔꿈치 중심은 보조 뼈를 따라가고, 그 주변은 위팔/아래팔로 부드럽게 연결.
- 기존 모델의 정점 위치, 폴리곤, UV, 표정 블렌드셰이프는 보존.
- 기존 뼈의 이름, 부모 관계, 기본 회전/위치와 기존 애니메이션 경로는 보존.
- 보조 뼈는 아래팔의 형제 뼈입니다. 기존 계층 사이에 삽입하지 않았습니다.

보조 뼈가 필요한 이유
아래팔만 큰 각도로 굽히면 팔꿈치 부분이 좁아질 수 있습니다.
보조 뼈를 아래팔 회전량의 절반만큼 움직여 접힘을 분산하도록 설계했습니다.
새 동작을 만들 때 보조 뼈도 함께 움직여야 수정된 웨이트가 올바르게 작동합니다.

포함 파일
Turtle_ElbowReady.fbx
  - Upright_Idle: 이전에 만든 우뚝 선 자세를 1초간 유지.
  - Elbow_Flex_Test: 팔을 앞으로 둔 상태로 0→30→60→90→0도 굽힘 테스트, 4초.
  두 클립은 보조 뼈 움직임도 기록되어 있어 Inspector에서 바로 미리볼 수 있습니다.
Runtime/TurtleElbowSupport.cs
  - 아래팔 회전에 맞춰 보조 뼈를 자동으로 따라 움직이게 하는 컴포넌트.
  - Drive Elbows를 켜면 Left Bend / Right Bend 슬라이더로 굽힘 각도를 조절.
Editor/TurtleElbowSetup.cs
  - 모델의 원래 기본 회전과 뼈 참조를 자동 설정하는 메뉴 및 Inspector 버튼.
Turtle_Elbow_Preview.gif / Elbow_Bend_Review.png
  - 실제 내보낸 FBX를 다시 읽어 만든 굽힘 미리보기.
Validation.json
  - 기본 모양, 원본 데이터 보존 및 FBX 재생 검증 기록.
rig_info.json
  - 보조 뼈 이름과 FBX 좌표계의 굽힘 축 참고값.

Unity에 넣기
1. 압축 안의 TurtleElbowReady 폴더를 Assets에 넣습니다.
   Editor 폴더와 Runtime 폴더의 위치를 그대로 유지하세요.
2. FBX 선택 > Rig:
   Animation Type = Generic
   Avatar Definition = Create From This Model
   Optimize Game Objects = 끔
   Apply합니다. 새 보조 뼈가 있으므로 새 모델에서 Avatar를 생성하세요.
3. Animation 탭에서 Import Animation을 켜고 Elbow_Flex_Test를 선택해 재생합니다.
   Upright_Idle도 선택할 수 있습니다. FBX의 바인드 포즈 자체는 원래 네 발 자세입니다.
4. 원래 쓰던 거북이 재질을 연결하세요. 미리보기 색상은 임시 단색입니다.

앞으로 새 동작을 만들 때
1. Turtle_ElbowReady.fbx를 씬에 넣습니다. 먼저 Unpack하지 마세요.
2. Hierarchy에서 그 모델의 최상위 오브젝트를 선택합니다.
3. Tools > Turtle > Configure Elbow Support를 실행합니다.
   원본 모델 에셋에서 기본 회전을 읽어오므로, 현재 자세를 잘못 기준으로 삼지 않습니다.
4. Turtle Elbow Support 컴포넌트가 추가됩니다.
   - Drive Elbows OFF: Animator나 직접 조절한 아래팔 회전을 보조 뼈가 따라갑니다.
   - Drive Elbows ON: Left Bend / Right Bend 슬라이더가 아래팔 회전을 덮어씁니다.
5. 확인하기 쉬운 방법은 Elbow_Flex_Test를 Animator에서 재생하면서
   Drive Elbows를 켜고 슬라이더를 조절하는 것입니다. 위팔은 앞으로 둔 채
   아래팔 굽힘 각도만 직접 조절할 수 있습니다.
6. 실제 애니메이션을 재생할 때는 Drive Elbows를 끄세요.
   수동 모드를 끈 것만으로 아래팔이 원래 각도로 복귀하지는 않습니다.
   Animator가 다음 자세를 적용하거나 수동으로 각도를 돌려놓으면 됩니다.
7. 설정 후 필요하면 새 일반 Prefab으로 저장할 수 있습니다.

애니메이션 제작 참고
- 기존 leg.F.L/R은 어깨/위팔 역할, leg.F.01.L/R은 아래팔 역할입니다.
- 이 모델의 본 축은 사람 리그의 일반적인 X축과 같지 않습니다.
  제공된 슬라이더는 모델에 맞는 굽힘 축을 사용합니다.
- 어깨의 방향과 비틀기를 먼저 잡고 팔꿈치를 굽히면 됩니다.
- 새 클립에서 보조 뼈를 직접 키프레임으로 제어하는 경우, 아래팔의 기본 회전
  대비 변화량의 절반을 보조 뼈에 적용하세요. 수치 Euler 각도를 단순히 반으로
  나누는 방식은 권장하지 않습니다. 제공된 컴포넌트는 Quaternion 보간을 사용합니다.
- 스크립트 없이 외부 프로그램에서 재생할 새 애니메이션은 보조 뼈 동작도
  해당 클립에 기록해야 합니다. 동봉된 테스트/기립 클립에는 기록되어 있습니다.
- 기존 걷기 등은 뼈 이름과 경로를 유지했지만, 이 모델과 함께 새로 검증한 것은
  아닙니다. 새 모델에 연결한 후 발/팔 움직임과 보조 뼈 동작을 확인하세요.
- LOD0만 수정했습니다. 다른 LOD에 적용하려면 보조 뼈 연결 및 웨이트 대응이 필요합니다.

품질과 확인 범위
기본 자세의 정점 위치는 원본과 수치 오차 수준으로 일치합니다.
원본 메시/UV/블렌드셰이프/기존 뼈 기본값을 보존했음을 검사했습니다.
별도의 FBX 리더에서 두 클립을 읽고 굽힘 테스트의 49개 시점을 확인했습니다.
90도까지 굽힘을 시험했으나 안쪽 주름과 눌림은 남습니다. 처음에는 60도 전후로
자세를 잡고 게임 카메라에서 확인하는 것을 권합니다.
Unity Editor가 없는 환경에서 제작하여 Unity 6000.3.15f의 임포트와 제공 C# 코드의
컴파일/실행은 직접 검증하지 못했습니다. 이 제한은 FBX 재생 검증과 별개입니다.
